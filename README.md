# Vibes — фронтенд (Лабораторная работа №5)

Базовое SPA для **гостя** на React + TypeScript с компонентами React-Bootstrap.
Дизайн перенесён из лабораторной №1 (зелёный акцент, колонка шириной 450 px,
видео-лента и плитка карточек).

В этой лабораторной **бэкенд не подключается**: содержимое карточек берётся
только из mock-коллекции `src/mocks/services.ts`. Форма объекта услуги совпадает
с ответом бэкенда (`ServiceOut`), поэтому в следующих лабораторных mock-данные
можно заменить на запросы к API.

## Запуск

Нужен Node.js 18 и новее.

```
npm install
npm run dev        # режим разработки, http://localhost:5173
npm run build      # проверка типов и сборка в папку dist
npm run preview    # просмотр собранной версии
```

## Что использовано и чего нет

- React 18, TypeScript, Vite
- React-Bootstrap (`Navbar`, `Nav`, `Card`, `Form`, `Button`, `Collapse`, `Badge`, `Row`, `Col`)
- react-router-dom, режим `HashRouter` (адреса вида `/#/feed/3`, работает на GitHub Pages)
- **Redux не используется**, **React Context в коде приложения не используется**.
  Состояние — только локальное (`useState`) внутри компонентов. Context есть
  внутри самих библиотек react-router и react-bootstrap, но в проекте он нигде
  не создаётся и не читается.

## Структура

```
src/
  main.tsx                точка входа (HashRouter)
  App.tsx                 маршруты и нижняя навигация
  types.ts                типы Service и Filters
  mocks/services.ts       mock-коллекция из 8 услуг
  assets/                 изображение и видео по умолчанию, картинки и видео для mock
  utils/media.ts          подстановка изображения/видео по умолчанию
  utils/filter.ts         фильтрация коллекции
  utils/format.ts         форматирование цены, КПД, даты
  components/             BottomNav, ServiceCard, Icon
  pages/                  FeedPage, TilesPage, NotFoundPage
  styles/app.css          стили из лабораторной №1
```

## Изображение и видео по умолчанию

Если у услуги `image_url` или `video_url` пустые (`null` или пустая строка),
подставляются файлы из проекта: `src/assets/default-panel.jpg` и
`src/assets/default-video.mp4` (функции `resolveImage` и `resolveVideo`
в `src/utils/media.ts`). В mock-коллекции у услуг №3, №5, №7, №8 нет изображения,
а у №2, №3, №5–8 нет видео — на них можно увидеть значения по умолчанию.

## Страницы приложения

| Адрес | Страница |
|---|---|
| `/#/feed` | Лента (первая услуга) |
| `/#/feed/:id` | Лента с услугой `id`; неизвестный `id` открывает первую услугу |
| `/#/tiles` | Плитка |
| любой другой | «Страница не найдена» |

### Нижняя навигация (на всех страницах)

Панель `Navbar` внизу экрана, 4 пункта:

| Пункт | Состояние | Действие |
|---|---|---|
| Лента | доступен | переход на `/#/feed` |
| Добавление | отключён | появится в следующих лабораторных |
| Плитка | доступен | переход на `/#/tiles` |
| Вход | отключён | появится при добавлении авторизации |

Текущая страница подсвечивается зелёным цветом.

### Страница «Лента»

Поля и элементы:

- **Видео** — на весь экран фоном, запускается само, без звука, по кругу;
  пока оно загружается, показывается изображение услуги.
- **Лайки** — иконка сердца и число (`likes_count`); только показ, гость
  поставить лайк не может.
- **Кнопка «Следующая карточка»** (стрелка) — показывает следующую услугу
  по кругу, адрес меняется на `/#/feed/{id}`.
- **КПД** — иконка молнии и значение в процентах.
- **Цена** — иконка и цена в ₽/м².
- **Карточка внизу** — название услуги и описание. Описание длиннее 80 символов
  обрезается, рядом показывается кнопка-ссылка **«Ещё»**, которая раскрывает
  полный текст; после раскрытия она называется **«Меньше»** и сворачивает текст.

### Страница «Плитка»

Фильтр (сворачивается кнопкой **«Фильтр»**, на ней число применённых условий):

| Поле | Тип | Как фильтрует |
|---|---|---|
| Название | текст | услуги, в названии которых есть введённый текст (без учёта регистра) |
| Дата с | дата | услуги, опубликованные не раньше выбранной даты |
| КПД не выше | ползунок 0–40 % | услуги с КПД не больше выбранного |
| Цена до, ₽/м² | число | услуги с ценой не выше введённой; пусто — без ограничения |

Кнопки фильтра:

- **«Отфильтровать»** — применяет условия из полей.
- **«Сбросить»** — возвращает все поля к значениям по умолчанию и показывает все услуги.
- Рядом показывается счётчик **«Найдено: N»**.

Условия применяются только после нажатия «Отфильтровать»; поля можно менять,
не перестраивая плитку на каждом нажатии.

Карточки услуг (сетка в две колонки): изображение, название, цена, дата
публикации, КПД, число лайков. Нажатие на карточку открывает эту услугу
в ленте. Если по условиям ничего не найдено, вместо сетки показывается
сообщение **«Ничего не найдено»**.

### Страница «Страница не найдена»

Показывается при неизвестном адресе. Кнопка **«Перейти к ленте»** ведёт на `/#/feed`.
