# Vibes — фронтенд (Лабораторная работа №5)

Базовое SPA для **гостя** на React + TypeScript с компонентами React-Bootstrap.
Дизайн перенесён из лабораторной №1 (зелёный акцент, колонка шириной 450 px,
видео-лента и плитка карточек).

В этой лабораторной **бэкенд не подключается**: содержимое карточек берётся
только из mock-коллекции `src/mocks/services.ts`. Форма объекта услуги совпадает
с ответом бэкенда (`ServiceOut`), поэтому в следующих лабораторных mock-данные
можно заменить на запросы к API.

## Запуск

Нужен Node.js 18 и новее.

```
npm install
npm run dev        # режим разработки, http://localhost:5173
npm run build      # проверка типов и сборка в папку dist
npm run preview    # просмотр собранной версии
```

## Что использовано и чего нет

- React 18, TypeScript, Vite
- React-Bootstrap (`Navbar`, `Nav`, `Card`, `Form`, `Button`)
- react-router-dom, режим `HashRouter` (адреса вида `/#/feed/3`, работает на GitHub Pages)
- **Redux не используется**, **React Context в коде приложения не используется**.
  Состояние — только локальное (`useState`) внутри компонентов.

Используемые хуки: `useState`, `useMemo`, `useRef`, `useEffect`
(React) и `useParams`, `useNavigate` (react-router).

## Как заменить свои фото и видео

### Фото карточек (плитка)

Файлы лежат в `src/assets/photos/` и называются `photo-<id услуги>.jpg`.
Сейчас фото есть у услуг №1, №2, №4, №6, у остальных поле `image_url` пустое
и показывается изображение по умолчанию.

1. **Заменить существующее фото** — положите свой файл в `src/assets/photos/`
   под тем же именем (`photo-1.jpg` и т. д.). Код менять не нужно.
2. **Добавить фото услуге без фото** (№3, №5, №7, №8) — положите файл,
   например `photo-3.jpg`, в ту же папку, затем в `src/mocks/services.ts`
   добавьте строку `import photo3 from '../assets/photos/photo-3.jpg';`
   и у этой услуги замените `image_url: null` на `image_url: photo3`.
3. **Изображение по умолчанию** — замените файл `src/assets/default-panel.jpg`.

Подойдёт `jpg`, `png` или `webp`; если расширение другое, поменяйте его
в строке `import`. Лучше горизонтальные фото с пропорциями 4:3 (например,
800×600): в карточке высота фиксирована и фото обрезается по центру.

### Видео ленты

Видео играет на заднем фоне ленты, без звука и по кругу.

1. **Одно видео для всех услуг** — замените файл `src/assets/default-video.mp4`
   своим (имя оставьте прежним). Сейчас там заглушка.
2. **Своё видео для отдельной услуги** — создайте папку `src/assets/videos/`,
   положите туда `video-1.mp4`, в `src/mocks/services.ts` добавьте
   `import video1 from '../assets/videos/video-1.mp4';` и у нужной услуги
   замените `video_url: null` на `video_url: video1`.

Рекомендации к видео: формат MP4 (H.264), вертикальное (9:16, например 540×960
или 720×1280), длительностью 5–15 секунд, небольшого размера (до 5–10 МБ).
Для зацикливания достаточно атрибута `loop` — следите, чтобы последний кадр
был похож на первый. После замены файла обновите страницу (Ctrl+F5).

## Страницы приложения

| Адрес | Страница |
|---|---|
| `/#/feed` | Лента (первая услуга) |
| `/#/feed/:id` | Лента с услугой `id`; неизвестный `id` открывает первую услугу |
| `/#/tiles` | Плитка |
| любой другой | «Страница не найдена» |

### Нижняя навигация (на всех страницах)

Панель `Navbar` внизу экрана, 4 пункта:

| Пункт | Состояние | Действие |
|---|---|---|
| Лента | доступен | переход на `/#/feed` |
| Добавление | отключён | появится в следующих лабораторных |
| Плитка | доступен | переход на `/#/tiles` |
| Вход | отключён | появится при добавлении авторизации |

Текущая страница подсвечивается зелёным цветом.

### Страница «Лента»

- **Видео** — на весь экран фоном, запускается само, без звука, повторяется
  по кругу; пока оно загружается, показывается изображение услуги.
- **Лайки** — иконка сердца и число (`likes_count`); только показ, гость
  поставить лайк не может.
- **Кнопка «Следующая карточка»** (стрелка) — показывает следующую услугу
  по кругу, адрес меняется на `/#/feed/{id}`.
- **КПД** — иконка молнии и значение в процентах.
- **Цена** — иконка и цена в ₽/м².
- **Карточка внизу** — название услуги и описание. Описание длиннее 80 символов
  обрезается, рядом показывается кнопка-ссылка **«Ещё»**, которая раскрывает
  полный текст; после раскрытия она называется **«Меньше»** и сворачивает текст.

### Страница «Плитка»

Фильтр по КПД:

| Элемент | Что делает |
|---|---|
| Ползунок «Фильтр по КПД» (0–40 %) | выбирает максимальный КПД; рядом показывается выбранное значение |
| Кнопка **«Отфильтровать»** | применяет выбранное значение: остаются услуги с КПД не выше него |
| Надпись «Найдено: N» | число услуг, подходящих под применённый фильтр |

Значение применяется только после нажатия «Отфильтровать»: ползунок можно
двигать, не перестраивая плитку.

Карточки услуг (сетка в две колонки): изображение (или изображение по
умолчанию), название, цена, дата публикации, КПД, число лайков. Нажатие на
карточку открывает эту услугу в ленте. Если подходящих услуг нет, вместо сетки
показывается сообщение **«Ничего не найдено»**.

### Страница «Страница не найдена»

Показывается при неизвестном адресе: изображение по умолчанию, текст и кнопка
**«Перейти к ленте»**, которая ведёт на `/#/feed`.
